# API Penjana Nombor Permohonan PUSBA

API ringkas dan pantas berasaskan **Node.js (Serverless)** yang dibangunkan untuk menjana nombor borang permohonan secara automatik berdasarkan **Mod (Mingguan/Bulanan)**, **Tahun**, **Kod Daerah (Kedah)**, dan **Nombor Turutan Permohonan**.

API ini hos secara *live* di **Vercel** dan disepadukan terus dengan repositori GitHub ini.
